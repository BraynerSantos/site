# Brayner Santos

Personal portfolio website for [Brayner Santos](https://braynersantos.com), built as a lightweight static landing page with a custom engineering-inspired aesthetic.

This repository contains the source for a minimal personal website designed to present a brief bio, active work, and key links in a clean, technical, and memorable visual style. The site is intentionally simple, fast, and easy to maintain without relying on frameworks, build tooling, or a backend.

## Overview

This project is a static website focused on clarity, performance, and identity:

- Plain HTML for structure
- Custom CSS for layout and styling
- Dark, technical visual language inspired by engineering sheets and blueprint layouts
- Responsive design for desktop and mobile screens
- No framework, package manager, or build step required

## Purpose

The site acts as a digital home base: a place to share who I am, what I’m building, and how to connect. The goal is to keep the experience clean and intentional while still feeling distinctive and strong enough to represent a personal brand.

## Homepage Content

The landing page includes:

- A hero section with a short introduction
- A project section highlighting current work
- Links to live projects and professional profiles
- A visual system inspired by drafting documents and technical layouts

## Local Development

Because this is a static site, it can be previewed directly in a browser or served locally with a simple Python web server.

Run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

This project is designed to be deployed as a static site on a lightweight hosting provider or static host. It does not require a backend, build pipeline, or application runtime.

## Technologies Used

- HTML5
- CSS3
- Static hosting

## Notes

This repository emphasizes simplicity, maintainability, and a strong visual identity over complexity. It is a small personal site built to be easy to host, easy to edit, and fast to load while still representing a polished and thoughtful portfolio presence.
